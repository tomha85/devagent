# DevAgent v0.7 — Engineering Breadth

v0.7 focuses on engineering work that previously required manual file operations or was only partially discoverable.

The release adds bounded structural refactor operations, expands repository-native verification into Java and .NET projects, qualifies a reversible SQLite migration against existing data, and hardens discovery for very large monorepositories. These capabilities continue to run through DevAgent's evidence, worktree, sandbox, review, and final-verification gates.
